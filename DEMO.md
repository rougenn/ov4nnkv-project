# 🎬 Демо-сценарий Meeting Assistant

Пошаговый сценарий на ~7-10 минут, покрывающий все ключевые функции: веб-интерфейс, Telegram-бот, запись Яндекс Телемост, создание встреч в Google Calendar с e-mail приглашениями, поиск по базе знаний с live-стримингом ответа.

---

## 🧰 Подготовка (10 секунд)

Открой в браузере **в отдельных вкладках**:

| Что | Куда |
|---|---|
| Веб-интерфейс | <http://localhost:5050> |
| Telegram-бот | <https://t.me/newrandombotforproject_bot> |
| Google Calendar | <https://calendar.google.com> |
| Gmail | <https://mail.google.com> |
| Личный кабинет Follow-Up | <https://lk.follow-up.tech> |
| (опц.) Telemost для теста записи | <https://telemost.yandex.ru> |

Проверь, что стек запущен:
```bash
docker compose ps
```
Все 6 контейнеров должны быть `Up`.

---

## 1. 🖥️ Открой веб-интерфейс — покажи дизайн (30 сек)

В <http://localhost:5050>:

1. **Hero-секция вверху**: «Запись, транскрипция и поиск по вашим встречам — через чат». Расскажи про 4 feature-карточки.
2. **Правая панель → Agent Card**: показывает что агент здоров, имя `Meeting Assistant`, версия `1.0.0`, **11 skills** в виде тегов (`join_conference`, `create_calendar_event`, `search_knowledge_base` и т.д.) — это все доступные инструменты.
3. **Зелёная точка** в правом верхнем углу — индикатор онлайн-статуса агента.

> 💡 Объясни: «Под капотом — LangChain агент, который умеет дёргать MCP-серверы. UI — это инспектор A2A-протокола».

## 2. 💬 Smoke: базовая болталка (15 сек)

В чате веб-интерфейса (левая панель) введи:

```
Привет! Расскажи коротко, что ты умеешь
```

Нажми **Отправить** (или ⌘/Ctrl+Enter).

✅ Ожидание: агент структурированно перечислит свои возможности.

Переключи правую панель на вкладку **JSON** — покажи сырой A2A request/response.

---

## 3. 📅 Календарь: текущее время + проверка расписания (20 сек)

```
Сколько сейчас времени в Москве и какие у меня встречи на сегодня?
```

✅ Агент дёрнет **сразу два tool'а**: `get_current_time_moscow` + `get_events_for_date` → ответит точным временем и скажет «встреч нет».

> 💡 Объясни: «Видите — он сам решает какой инструмент вызвать. Никаких хардкод-команд».

## 4. 📅 Создание встречи с приглашением на твою почту (1 мин)

**Ключевой шаг — на твой Gmail придёт настоящее письмо.** Замени email на свой:

```
Создай встречу «Демо Meeting Assistant» на завтра в 16:00 на 30 минут. Добавь Google Meet и пригласи участника blaz3n.hi@gmail.com
```

✅ Что произойдёт:
- Агент дёрнет `create_calendar_event` с правильными ISO-датами (`2026-05-27T16:00:00`)
- Создаст событие в общем календаре `e11fe8be...@group.calendar.google.com`
- Добавит автоматически сгенерированную Google Meet ссылку
- Отправит приглашение на твою почту

🔍 **Что показать аудитории сразу после:**
1. Открой <https://mail.google.com> — должно прийти **письмо-приглашение** от Google Calendar с темой «Демо Meeting Assistant» и Meet-ссылкой
2. Открой <https://calendar.google.com> → завтра в 16:00 — встреча там
3. Кликни на встречу → видна Google Meet ссылка → можно нажать «Join»

> 💡 Объясни: «Агент сам распарсил "завтра в 16:00 на 30 минут" в ISO-формат, сам определил что нужен Meet, сам добавил participant».

Если хочешь — попроси посмотреть список:
```
Покажи мои встречи на ближайшие 7 дней
```
✅ Покажет только что созданную встречу.

## 5. 🎙️ Запись Яндекс Телемост (1.5 мин)

**Сначала — открой и активируй комнату Телемоста**, иначе бот не сможет в неё зайти:

1. Открой <https://telemost.yandex.ru> → нажми **«Создать встречу»**
2. Скопируй ссылку (формат `https://telemost.yandex.ru/j/XXXXXXXXXXXX`)
3. **Зайди в саму комнату** (нажми «Присоединиться») — комната должна быть открытой и активной
4. **Не закрывай вкладку** с Телемостом — оставь её открытой

Теперь в чате веб-интерфейса:

```
Подключись к созвону <вставь_ссылку> и запиши его, тема «Демо запись»
```

✅ Что произойдёт:
- Агент дёрнет `join_conference` через Follow-Up MCP
- Follow-Up API ответит `conference_id` (UUID)
- В вашем личном кабинете Follow-Up появится новая запись
- **В Telemost-комнате должен запросить впуск участник «Follow-Up Bot»** — впусти его

🔍 **Что показать:**
1. Telemost-комната → новый участник `Follow-Up Bot`
2. <https://lk.follow-up.tech> — новая запись со статусом `recording` / `connecting`

> 💡 Объясни: «Бот теперь записывает звук и видео, после окончания будет транскрипция».

Если зрителям нужно — попроси:
```
Покажи список моих последних записанных созвонов
```
✅ Покажет историю + новую запись.

## 6. 🧠 База знаний: запоминаем факты (1 мин)

Это покажет работу локального RAG (sentence-transformers + cosine, без облака):

Введи **3 факта подряд** (по одному запросу за раз):

```
Запомни в базу знаний: на встрече 12 мая обсудили Q3-бюджет. Выделили 500к на маркетинг и 300к на инфраструктуру. Ответственный — Иван Петров.
```

```
Запомни: на ретро 18 мая решили перенести релиз с 25 мая на 1 июня из-за проблем с тестами. Решение принял CTO.
```

```
Запомни: на стендапе 20 мая Пётр Сидоров взял задачу по миграции базы данных, дедлайн — пятница 24 мая.
```

✅ Каждый раз агент дёрнет `add_to_knowledge_base` → сохранит в локальный JSON (volume `rag-store` в Docker).

## 7. 🔍 Поиск по базе знаний (45 сек)

Теперь **семантический поиск** — даже без точных слов агент найдёт релевантное:

```
Что у нас известно про бюджет на следующий квартал?
```
✅ Найдёт первый факт про Q3-бюджет.

```
Когда теперь релиз?
```
✅ Найдёт факт про перенос на 1 июня.

```
Кто отвечает за миграцию БД?
```
✅ Найдёт факт про Петра Сидорова.

> 💡 Объясни: «Это семантический поиск через эмбеддинги. Я нигде не сказал слово "миграция", но он нашёл по смыслу. Хранится локально в JSON — никаких облачных RAG-сервисов».

## 8. 📱 Тот же агент через Telegram-бот (1 мин)

Открой <https://t.me/newrandombotforproject_bot> → `/start`.

✅ Бот автоматически подключится к агенту (без лишних кликов).

Покажи **готовые slash-команды** (Telegram сам подскажет):
- `/upcoming 7` — встречи на 7 дней (увидишь «Демо Meeting Assistant»)
- `/search бюджет` — RAG-поиск по транскрипциям
- `/summary <id>` — саммари созвона по ID
- `/help` — справка

## 9. ⚡ Live-стриминг ответа в Telegram (30 сек)

**Killer feature** — сообщение бота меняется в реальном времени.

Спроси что-то сложное (требует tool-call):

```
Найди все факты про релиз и бюджет, и расскажи подробно что мы знаем
```

✅ Сообщение «🤔 Думаю…» меняется:
1. Появляется «🔧 Использую инструмент: search_knowledge_base»
2. Постепенно подгружается текст ответа
3. Финальный edit — полный ответ

> 💡 Объясни: «Это через A2A `message/stream` SSE. Не блокирующий запрос — пользователь сразу видит что агент работает».

## 🆘 Если что-то пошло не так

| Проблема | Решение |
|---|---|
| Агент не отвечает | `docker compose logs -f agent` — посмотреть ошибки |
| Calendar не создаётся | Проверь что OAuth-токен живой: `docker compose logs mcp-google-calendar` |
| Telemost-бот не зашёл | Проверь что комната активна; см. `docker compose logs mcp-followup`; зайди в lk.follow-up.tech |
| RAG не находит | `docker compose restart mcp-rag-local` — embedder перечитает данные |
| TG-бот молчит | `docker compose restart telegram-bot` |
| Сайт не открывается | `docker compose ps demo-app` → должен быть `Up`; порт `5050` |

Любой сервис можно рестартануть отдельно:
```bash
docker compose restart agent
docker compose logs -f agent --tail 30
```
