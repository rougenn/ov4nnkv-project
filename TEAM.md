# Команда

## Даниил Ананьев — агент

Делал основную часть агента. Подключал LangChain, написал tool-calling — это когда LLM сама решает какой инструмент вызвать. Подключал OpenRouter (по умолчанию gpt-4o-mini), на всякий случай предусмотрел переключение на Gemini и обычный OpenAI — поменять надо только три env-переменные.

Писал A2A-обёртку — чтобы агент работал по протоколу agent-to-agent, и его можно было дёргать снаружи через JSON-RPC. Системный промпт тоже его — большой кусок русского текста, который описывает агенту что он умеет и как реагировать на запросы.

Файлы: `agent/src/agent.py`, `prompts.py`, `a2a_wrapper.py`, `start_a2a.py`.

## Святослав Савинов — RAG

Сделал локальный поиск по знаниям, чтобы не зависеть от облачных RAG-сервисов. Эмбеддинги через sentence-transformers (модель `paraphrase-multilingual-MiniLM-L12-v2`, мультиязычная, 384 dim), хранение в обычном JSON, поиск — cosine similarity через NumPy.

Завернул всё в MCP-сервер с tools `search` / `add_document` — агент видит их как обычные функции. На macOS пришлось форсить CPU и отключать xet-downloader, иначе процесс крашился при первой загрузке модели.

Файлы: `mcp-rag-local/src/store.py`, `server.py`, `Dockerfile`.

## Алан Халибеков — внешние API

Сделал два MCP-сервера для интеграций. Один — с Follow-Up, который реально подключается к Google Meet, Zoom, Teams, Яндекс Телемост и Jitsi и записывает звонок. Внутри — JWT-логин, авто-рефреш токена, парсинг URL для каждой платформы (для каждой свой формат meeting ID).

Второй — Google Calendar через OAuth2. Умеет создавать события, рассылать приглашения по почте и автоматически добавлять Google Meet ссылку. Тут пришлось разбираться с разницей между Service Account и OAuth — SA удобнее, но не умеет рассылать invites по email, поэтому в итоге через OAuth.

Файлы: `mcp-followup/`, `mcp-google-calendar/`.

## Артур Аракелян — Telegram-бот и инфра

Telegram-бот на aiogram 3 — авто-подключение к агенту при `/start`, slash-команды (`/upcoming`, `/summary`, `/search`, `/help`), и главное — live-стриминг ответа. Когда агент дёргает инструмент, сообщение в чате обновляется в реальном времени: сначала «🤔 Думаю…», потом «🔧 Использую инструмент: …», потом финальный ответ. Сделано через A2A `message/stream` + SSE-парсер + дросселирование `edit_message_text` (Telegram режет если чаще 30/мин).

Плюс упаковал всё в docker-compose — 6 контейнеров, приватная сеть, volume для кеша модели эмбеддингов (470 МБ — скачивать каждый раз больно). Настроил GitHub Actions: ruff + pytest, integration-тесты к OpenRouter выключены чтобы не палить токены.

Файлы: `telegram-bot/`, `docker-compose.yml`, все Dockerfile, `.github/workflows/ci.yml`.
